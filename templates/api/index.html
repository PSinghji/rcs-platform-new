Authentication flow
  1. Send your username and password to POST /api/v1/auth/token.
  2. Store the returned access token securely.
  3. Create a template, check its approval status, then list approved templates to obtain a valid template_id.
  4. Upload the campaign numbers, monitor campaign status, and download the report.
curl -X POST "{{ request.base_url }}api/v1/auth/token" \
  -H "Content-Type: application/json" \
  -d '{"username":"YOUR_USERNAME","password":"YOUR_PASSWORD"}'

Campaign creation requirements
  • Call GET /api/v1/templates/approved and use the required template id as template_id.
  • The server automatically generates an idempotency key for campaign creation. Supplying an optional Idempotency-Key is supported when your integration needs to retry the same request safely.
  • CSV, TXT, or XLSX upload supports up to 500,000 unique valid Indian mobile numbers and a 20 MB file. XLSX files must contain a Mobile column in the first worksheet.
  • Users can monitor and download only their own campaigns. Administrators can access any campaign by ID.
